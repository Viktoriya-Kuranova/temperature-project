# Таблица температур
Это программа на C++,которая читает из файлов таблицы температур в разных шкалах (C,K,F). Таблицы хранятся в виде двумерных матриц, что позволяет выполнять над ними различные операции (подробнее в *возможностях*)
## Возможности программы
- проверка корректности входных данных (как по написанию, так и физически возможных)
- хранение таблиц произвольного размера
- автоматический перевод в градусы по Цельсию (C) во время вычислений
- наличие меню
- ***Операции***:
  - вывод таблицы на экран
  - нахождение минимальной температуры по строке таблицы
  - нахождение максимальной температуры по всей таблице
  - подсчет среднего значения по всей таблице
  - сложение таблиц (поэлементно) с приведением шкал

## Меню программы

| Пункт | Действие |
|-------|----------|
| 1 | Прочитать файлы заново и вывести обе таблицы на экран |
| 2 | Средняя температура по указанной строке  |
| 3 | Минимальная температура по указанной строке  |
| 4 | Сложить две таблицы поэлементно и вывести результат |
| 5 | Максимальная температура по таблице 1  |
| 0 | Выход |


## Требования
- компилятор C++ с поддержкой C++11 или новее
- файлы "input1.txt" и "input2.txt" с исходными данными

## Требования и ограничения входных данных
Первая строка файла - размеры таблицы (матрицы),т.е. количество строк и столбцов
Последующие строки: попарно значение и шкала через пробел построчно

**Правила:**
- значение обязательно должно быть вещественным числом
- шкала = C,K или F
- значения должны соответствовать физическим возможностям:
  - K>0
  - C>-273.15
  - F>-459.67
- количество пар должно совпадать с первой строкой (заданными размерами)

## Обработка ошибок
Программа сообщит об ошибке, если:
- файл не открывается
- размеры таблицы заданы не положительными числами
- данных в файле недостаточно или больше чем нужно
- использована неизвестная шкала
- температура физически невозможна
- не удалось выделить память
- требуется сложить таблицы разных размеров
- запрос на несуществующую строку
